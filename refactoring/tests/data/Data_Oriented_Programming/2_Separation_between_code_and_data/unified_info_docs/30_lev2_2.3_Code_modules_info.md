## Core 내용
DOP에서 코드 모듈은 상태를 갖지 않는 함수들의 집합으로, 데이터 엔티티를 조작하는 역할을 합니다. 각 함수는 데이터 엔티티를 인자로 받으며, 데이터 중심 설계가 핵심입니다.

## 상세 핵심 내용
DOP에서 코드 모듈은 시스템의 기능을 나타내는 함수들을 포함하며, 각 함수는 데이터 엔티티를 첫 번째 인자로 받습니다. 코드 모듈은 상태를 갖지 않으며, 데이터 중심 설계를 통해 모듈 간의 상호 작용을 명확하게 정의합니다. 본 챕터에서는 코드 모듈 설계 원칙, OOP와의 비교, 고수준 모듈 구성에 대해 다룹니다.

## 상세 정보 내용
본 챕터는 DOP에서의 코드 모듈 정의, 설계 원칙, OOP와의 비교, 고수준 모듈 구성에 대한 내용을 담고 있습니다. Python에서의 데이터 전달 방식과 라이브러리 관리 시스템 예시를 통해 구체적인 이해를 돕습니다.

## 주요 화제
*   DOP에서의 코드 모듈 정의
*   DOP 코드 모듈 설계 원칙 (stateless, explicit data argument)
*   전통적인 OOP와 DOP에서의 함수 인자 전달 방식 비교
*   고수준 모듈 구성 (데이터 엔티티 기반)

## 부차 화제

*   Python에서의 self와 DOP의 데이터 전달 방식 비교
*   Library Management System의 예시

In traditional OOP, the state of the object is an implicit argument to the meth-

Joe

  }

The state of the library is stored in libraryData, and libraryData is passed
to the getBookLendings static method as an explicit argument.
Theo
Is that a general rule?
Joe
Absolutely! The same rule applies to the other functions of the Library mod-

the library data that they manipulate as an argument.
TIP
In DOP, functions of a code module are stateless. They receive the data that they
manipulate as an explicit argument, which is usually the first argument.

stateless.
