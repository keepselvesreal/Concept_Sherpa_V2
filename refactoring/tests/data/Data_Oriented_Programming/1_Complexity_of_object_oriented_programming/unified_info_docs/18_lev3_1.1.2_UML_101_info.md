## 핵심 내용
이 문서는 UML 다이어그램의 기본 개념과 다양한 관계 유형(composition, association, inheritance, usage)을 설명한다. 도서관 관리 시스템을 예시로 들어 클래스 다이어그램을 분석하며, 각 관계의 의미와 표현 방식을 설명한다. 객체 지향 프로그래밍(OOP)에서 사용되는 용어들을 쉽게 이해할 수 있도록 돕는 것을 목표로 한다.

## 상세 핵심 내용
UML 101은 객체 지향 프로그래밍의 복잡성을 이해하기 위한 챕터의 일부로, UML 다이어그램을 소개한다. 다이어그램은 도서관 관리 시스템의 예시를 통해 클래스, 속성, 메서드, 관계 등을 보여준다. 주요 관계 유형은 composition(one-to-one, one-to-many), association(many-to-many), inheritance, usage이다. Composition은 한 객체가 죽으면 다른 객체도 함께 죽는 관계이며, association은 독립적인 생명 주기를 갖는다. Inheritance는 빈 삼각형이 있는 일반 화살표로, usage는 점선 화살표로 표현된다.

## 상세 정보
*   **문서 제목:** 18 lev3 1.1.2 UML 101
*   **주요 내용:** UML 다이어그램 소개 및 OOP 개념 설명
*   **주요 관계 유형:**
    *   Composition: 한 객체가 죽으면 다른 객체도 죽음 (plain diamond)
    *   Association: 독립적인 생명 주기 (empty diamond)
    *   Inheritance: 클래스 상속 (plain arrow with empty triangle)
    *   Usage: 한 클래스가 다른 클래스의 메서드를 사용 (dashed arrow)
*   **예시:** 도서관 관리 시스템 클래스 다이어그램 (Librarian, Member, Book, Author 등)
*   **각 관계의 표현:**
    *   Composition: plain diamond와 optional star
    *   Association: empty diamond와 star
    *   Inheritance: plain arrow with empty triangle
    *   Usage: dashed arrow
*   **참고:** OOP 용어에 익숙하지 않아도 다음 챕터에서 다루지 않음.

In the class diagram, there are two kinds of composition symbolized by an arrow with
a plain diamond at one edge and an optional star at the other edge. Figure 1.2 shows
the relation between:
A Library that owns a Catalog—A one-to-one composition. If a Library object
dies, then its Catalog object dies with it.
A Library that owns many Members—A one-to-many composition. If a Library
object dies, then all its Member objects die with it.
TIP
A composition relation is represented by a plain diamond at one edge and an
optional star at the other edge.
Dave

Take a look at the arrow between Book and Author. It has an empty diamond
and a star at both edges, so it’s a many-to-many association relation.
A book can be written by multiple authors, and an author can write multiple books.
Moreover, Book and Author objects can live independently. The relation between
books and authors is a many-to-many association (figure 1.3).
