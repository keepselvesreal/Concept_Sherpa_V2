## 7.4 Schema composition 상세 분석 및 추가 정보

다음은 "7.4 Schema composition"의 내용을 분석하여, 기존 내용에서 다루지 않은 추가적인 상세 정보와 새로운 내용들을 식별하여 정리한 내용입니다.

**1. 외부 API 응답 데이터 검증의 필요성:**

*   **상세 정보:** 외부 웹 서비스(예: Open Library Books API)에서 제공하는 데이터의 유효성을 검증해야 하는 필요성을 제기합니다.  이는 외부 서비스의 데이터 구조가 변경될 경우, 애플리케이션의 동작에 오류가 발생할 수 있기 때문입니다.
*   **추가 정보:** 외부 서비스의 데이터 구조는 통제할 수 없으므로, 스키마를 사용하여 응답 데이터를 검증하는 것은 데이터 무결성을 보장하고 잠재적인 오류를 방지하는 데 필수적입니다.

**2. `isbn_10` 및 `isbn_13` 필드의 문제점과 해결 방법:**

*   **상세 정보:**  `isbn_10`과 `isbn_13` 필드가 모두 필수적인 것은 아니며, 책의 출판 연도에 따라 하나 또는 둘 다 존재할 수 있다는 점을 지적합니다.
*   **추가 정보:**  이러한 유연성을 표현하기 위해 JSON Schema의 "Schema composition" 기능을 사용합니다.  즉, `isbn_10` 또는 `isbn_13` 중 하나 이상이 존재해야 하는 조건을 스키마로 표현합니다.

**3. JSON Schema Composition:**

*   **상세 정보:**  JSON Schema composition은 여러 스키마를 조합하여 더 복잡한 데이터 유효성 검사 규칙을 정의하는 방법입니다.
*   **추가 정보:**
    *   `allOf`:  AND 연산과 유사하며, 데이터가 모든 하위 스키마를 만족해야 합니다.
    *   `anyOf`:  OR 연산과 유사하며, 데이터가 적어도 하나의 하위 스키마를 만족해야 합니다.
    *   `oneOf`:  데이터가 정확히 하나의 하위 스키마를 만족해야 합니다. (본문에서는 언급만 됨)
*   **구체적인 구현:**  Open Library Books API 응답에 대한 예시를 통해 `allOf`와 `anyOf`를 사용한 스키마 조합을 보여줍니다.  이는 기본 정보 스키마(`basicBookInfoSchema`)와 `isbn_10` 또는 `isbn_13`을 포함하는 스키마를 결합하는 방식으로 구현됩니다.

**4. 코드 예시 (Listing 7.18 및 7.19) 상세 분석:**

*   **Listing 7.18:**
    *   `basicBookInfoSchema`: `title` 필드가 필수이며, 다른 필드들의 타입(type)을 정의합니다.
    *   `mandatoryIsbn13`:  `isbn_13` 필드가 필수임을 정의합니다.
    *   `mandatoryIsbn10`: `isbn_10` 필드가 필수임을 정의합니다.
    *   `bookInfoSchema`:  `basicBookInfoSchema`와 `anyOf`를 사용하여 `mandatoryIsbn13` 또는 `mandatoryIsbn10`을 결합합니다.  즉, `title`은 필수이고, `isbn_10` 또는 `isbn_13` 중 하나 이상이 존재해야 합니다.
*   **Listing 7.19:**  `bookInfoSchema`를 사용하여 "Watchmen" 책의 데이터를 검증하는 예시를 보여줍니다.  데이터가 유효하므로 검증 결과는 `true`입니다.

**5. JSON Schema Composition의 장점:**

*   **상세 정보:**  JSON Schema composition은 클래스를 사용하여 데이터를 표현하는 것보다 더 강력한 데이터 유효성 검사 규칙을 표현할 수 있게 해줍니다.
*   **추가 정보:**  데이터 모델의 유연성을 높이고, 다양한 데이터 구조에 대한 유효성 검사를 효율적으로 수행할 수 있습니다.  또한, 데이터의 특정 부분에 대한 규칙을 재사용할 수 있습니다.

**6. 검증 실패 시 문제점:**

*   **상세 정보:** 데이터가 유효하지 않을 경우, 어떤 이유로 실패했는지 명확하게 알 수 없다는 점을 지적합니다.
