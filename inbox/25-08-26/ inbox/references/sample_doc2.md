# 함수형 프로그래밍과 DOP

함수형 프로그래밍과 데이터 지향 프로그래밍은 많은 공통점을 가지고 있습니다.

## 공통 원칙

1. **불변성(Immutability)**: 데이터가 변경되지 않음
2. **순수 함수**: 부작용이 없는 함수 사용
3. **컴포지션**: 작은 단위를 조합하여 복잡한 로직 구성

## 차이점

- **FP**: 함수를 1급 객체로 취급
- **DOP**: 데이터 구조에 더 집중

## 실제 활용 사례

- Redux (React 상태 관리)
- Clojure 언어
- Immutable.js 라이브러리
