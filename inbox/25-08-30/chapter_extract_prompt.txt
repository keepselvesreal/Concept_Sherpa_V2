목차 정보를 분석하여 장별로 분리해주세요.

요구사항:
1. 각 메인 챕터(장)를 독립적인 그룹으로 분리
2. 각 장에는 해당 장의 모든 하위 섹션들이 포함되어야 함
3. 결과는 JSON 형태로 제공 (장 제목을 키로 사용)

출력 형식:
{
  "장 제목1": [
    {장 정보와 모든 하위 섹션들},
    ...
  ],
  "장 제목2": [
    {장 정보와 모든 하위 섹션들},
    ...
  ]
}

각 항목은 원본 목차 데이터의 모든 필드를 유지해주세요 (id, title, level, page, parent_id, children_ids, start_page, end_page, page_count 등).
