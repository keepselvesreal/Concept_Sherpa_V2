## 핵심 내용

이 문서는 UML 다이어그램에서 사용되는 화살표의 종류(composition, association, inheritance, usage)와 그 의미를 설명합니다. Composition은 객체 간의 생명주기 의존성을, association은 독립적인 객체 간의 관계를 나타내며, inheritance는 클래스 간의 상속 관계, usage는 클래스가 다른 클래스의 메서드를 사용하는 관계를 나타냅니다. 각각의 관계는 특정 형태의 화살표로 표현됩니다.

## 상세 핵심 내용

이 문서는 UML(Unified Modeling Language) 다이어그램, 특히 클래스 다이어그램의 기본 개념을 설명한다. 클래스 다이어그램은 객체 간의 관계를 시각적으로 표현하며, 여기서는 도서관 관리 시스템을 예시로 사용한다. 중요한 관계로 **연관 관계**, **합성 관계**, **의존 관계**, **상속 관계**의 네 가지 주요 화살표 유형을 설명한다. **합성 관계**는 객체 생명주기가 서로 의존적인 관계, **연관 관계**는 독립적인 관계를 나타낸다. **의존 관계**는 한 클래스가 다른 클래스의 메서드를 사용하는 경우를 보여주며, **상속 관계**는 클래스가 다른 클래스로부터 속성을 상속받는 관계를 나타낸다. 이러한 관계를 이해하는 것은 객체 지향 프로그래밍 설계를 효과적으로 시각화하고 소통하는 데 중요하다.

## 주요 화제

다음은 문서의 주요 화제입니다.

*   **UML (Unified Modeling Language):**
    *   UML 클래스 다이어그램의 예시 (도서관 관리 시스템)
    *   UML 다이어그램 내 화살표 (관계)의 의미 설명
*   **객체 지향 프로그래밍 (OOP):**
    *   객체 지향 설계의 복잡성
    *   클래스 다이어그램을 이용한 객체 관계 표현
*   **클래스 다이어그램 내 관계의 종류:**
    *   Composition (합성 관계): 생명 주기 의존성
    *   Association (연관 관계): 독립적인 생명 주기
    *   Usage (사용 관계): 클래스 간 메서드 호출
    *   Inheritance (상속 관계): 클래스 간 상속
*   **도서관 관리 시스템:**
    *   UML 클래스 다이어그램 예시로 사용
    *   클래스 예시: Librarian, Member, Catalog, Library, Book, Author, BookItem, BookLending, User

In the class diagram, there are two kinds of composition symbolized by an arrow with

A Library that owns many Members—A one-to-many composition. If a Library
