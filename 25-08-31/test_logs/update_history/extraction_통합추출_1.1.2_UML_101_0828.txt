TIP
In a composition relation, when one object dies, the other one also dies. While
in an association relation, each object has an independent life cycle.
In the class diagram, there are two kinds of composition symbolized by an arrow with
a plain diamond at one edge and an optional star at the other edge. Figure 1.2 shows
the relation between:
A Library that owns a Catalog—A one-to-one composition. If a Library object
dies, then its Catalog object dies with it.
A Library that owns many Members—A one-to-many composition. If a Library
object dies, then all its Member objects die with it.
TIP
A composition relation is represented by a plain diamond at one edge and an
optional star at the other edge.

## 핵심 내용
이 문서는 UML 다이어그램에서 사용되는 주요 관계인 composition, association, usage, inheritance를 설명한다. Theo와 Dave의 대화를 통해 각 관계의 특징과 시각적 표현 방법을 예시와 함께 제시하여 독자의 이해를 돕는다. 특히 composition과 association의 차이점을 객체의 생명주기를 기준으로 명확히 구분한다.

## 상세 핵심 내용
Theo는 Dave에게 도서관 관리 시스템의 UML 클래스 다이어그램을 보여주며, 다이어그램에 사용된 네 가지 관계(composition, association, usage, inheritance)를 설명한다. Composition은 객체 간의 생명주기가 종속적인 관계이며, association은 독립적인 관계이다. Usage는 한 클래스가 다른 클래스의 메서드를 사용하는 경우를 나타내며, inheritance는 클래스가 다른 클래스로부터 상속받는 관계를 나타낸다. 각 관계는 UML 다이어그램에서 특정 모양의 화살표로 표현되며, 이를 통해 클래스 간의 관계를 시각적으로 명확하게 나타낼 수 있다.

## 상세 정보
*   **UML 클래스 다이어그램**: Theo가 만든 도서관 관리 시스템의 UML 클래스 다이어그램이 제시된다.
*   **Composition**: 객체 간 생명주기가 종속적인 관계. Library와 Catalog(one-to-one), Library와 Member(one-to-many)의 예시가 제공된다. 다이어그램에서 plain diamond와 optional star로 표현된다.
*   **Association**: 객체 간 생명주기가 독립적인 관계. Book과 Author 간의 many-to-many 관계가 예시로 제시된다. 다이어그램에서 empty diamond와 star로 표현된다.
*   **Usage**: 한 클래스가 다른 클래스의 메서드를 사용하는 관계. Librarian::blockMember가 Member::block을 호출하는 예시가 제공된다. 다이어그램에서 dashed arrow로 표현된다.
*   **Inheritance**: 클래스가 다른 클래스로부터 상속받는 관계. Member가 User로부터 상속받는 예시가 제공된다. 다이어그램에서 empty triangle이 있는 plain arrow로 표현되며, arrow는 superclass를 가리킨다.
*   **각 관계의 시각적 표현**: Composition(plain diamond), Association(empty diamond), Usage(dashed arrow), Inheritance(empty triangle이 있는 plain arrow) 등 각 관계를 나타내는 UML 기호 설명.
