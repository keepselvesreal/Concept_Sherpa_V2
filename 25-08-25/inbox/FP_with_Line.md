1:  # 함수형 프로그래밍 (Functional Programming)
2:  
3:  ## 🎯 함수형 프로그래밍 (FP) 핵심
4:  
5:  ### 기본 개념
6:  **함수를 일급 시민으로 취급**하고 **순수 함수**를 기반으로 프로그램을 구성하는 방식
7:  
8:  ### 핵심 원리
9:  
10: **1. 순수 함수 (Pure Functions)**
11: - 같은 입력 → 항상 같은 출력
12: - 부작용(side effect) 없음
13: 
14: **2. 불변성 (Immutability)**
15: - 데이터를 변경하지 않음
16: - 새로운 데이터를 생성하여 반환
17: 
18: **3. 고차 함수 (Higher-Order Functions)**
19: - 함수를 인자로 받거나 함수를 반환
20: - `map`, `filter`, `reduce` 등
21: 
22: **4. 함수 합성 (Function Composition)**
23: - 작은 함수들을 조합하여 복잡한 기능 구현
24: 
25: ## 💡 간단한 예시
26: ```python
27: # 순수 함수
28: def add(x, y):
29:     return x + y  # 부작용 없음
30: 
31: # 고차 함수
32: numbers = [1, 2, 3, 4, 5]
33: doubled = list(map(lambda x: x * 2, numbers))  # [2, 4, 6, 8, 10]
34: evens = list(filter(lambda x: x % 2 == 0, numbers))  # [2, 4]
35: ```
36: 
37: ## 🏆 장점
38: - **예측 가능성**: 순수 함수로 버그 줄임
39: - **테스트 용이**: 입출력이 명확
40: - **병렬 처리**: 불변성으로 안전한 동시성
41: - **재사용성**: 작은 함수들의 조합
42: 
43: ## ⚖️ OOP vs FP
44: - **OOP**: 데이터 중심, 객체 상태 변경
45: - **FP**: 함수 중심, 데이터 변환 체인
