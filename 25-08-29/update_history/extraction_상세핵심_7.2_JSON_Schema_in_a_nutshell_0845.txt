### 7.2 JSON Schema in a nutshell 개요

이 챕터는 JSON Schema를 사용하여 데이터 유효성 검사를 수행하는 방법을 소개합니다. 특히, 도서 검색 요청에 대한 데이터 스키마를 정의하고, 해당 스키마를 기반으로 데이터의 유효성을 검사하는 과정을 단계별로 설명합니다. JSON Schema는 데이터 표현과 별도로 스키마를 정의하여 데이터 유효성 검사를 수행하는 데 사용되는 강력한 도구입니다.

### 데이터 유효성 검사의 중요성

*   데이터 유효성 검사는 데이터가 스키마에 정의된 규칙을 준수하는지 확인하는 과정입니다.
*   유효성 검사를 통해 데이터 무결성을 유지하고, 시스템 오류를 방지할 수 있습니다.
*   JSON Schema는 언어 독립적이며, 다양한 프로그래밍 언어에서 사용 가능한 라이브러리를 제공합니다.

### JSON Schema 소개

*   JSON Schema는 JSON 기반 데이터의 구조와 유효성을 정의하기 위한 스키마 언어입니다.
*   JSON Schema는 데이터 타입, 필수 필드, 허용된 값 등을 정의할 수 있습니다.
*   JSON Schema는 데이터 표현과 분리되어 관리되므로, 데이터 유효성 검사를 유연하게 수행할 수 있습니다.

### 도서 검색 요청 스키마 정의

1.  **요청 유형 정의:** 도서 검색 요청은 JSON 객체(object)로 표현됩니다.
    ```json
    {
      "type": "object",
      "properties": {...}
    }
    ```
2.  **속성 정의:** `properties` 필드를 사용하여 객체의 각 필드에 대한 스키마를 정의합니다.
    *   **title:** 문자열(string) 타입.
        ```json
        "title": {"type": "string"}
        ```
    *   **fields:** 문자열 배열(array) 타입.
        ```json
        "fields": {"type": "array"}
        ```
        *   **fields 배열의 요소 타입 정의:** `items` 필드를 사용하여 배열 요소의 타입을 지정합니다.
            ```json
            "fields": {
              "type": "array",
              "items": {"type": "string"}
            }
            ```
        *   **fields 배열의 허용된 값 정의:** `enum` 키워드를 사용하여 허용된 값의 목록을 지정합니다.
            ```json
            "fields": {
              "type": "array",
              "items": {
                "enum": [
                  "publishers",
                  "number_of_pages",
                  "weight",
                  "physical_format",
                  "subjects",
                  "publish_date",
                  "physical_dimensions"
                ]
              }
            }
            ```
3.  **필수 필드 정의:** `required` 필드를 사용하여 필수 필드를 지정합니다.
    ```json
    "required": ["title", "fields"]
    ```

### JSON Schema를 이용한 데이터 유효성 검사

*   JSON Schema를 사용하여 정의된 스키마에 따라 데이터의 유효성을 검사합니다.
*   다양한 프로그래밍 언어에서 JSON Schema 유효성 검사 라이브러리를 사용할 수 있습니다. (예: Ajv, Snow, JSON.net Schema, jschon, JSONSchemer)
*   유효성 검사 라이브러리는 스키마와 데이터를 입력으로 받아 데이터의 유효성 여부를 `true` 또는 `false`로 반환합니다.
*   유효하지 않은 데이터의 경우, 유효성 검사 라이브러리는 실패 이유에 대한 정보를 제공할 수 있습니다.

### JSON Schema의 장점

*   언어 독립성: 다양한 프로그래밍 언어에서 사용 가능합니다.
*   표현력: 클래스 기반의 데이터 표현 방식보다 더 복잡한 유효성 검사 조건을 표현할 수 있습니다. (예: 범위, 정규식)
*   유연성: 데이터 표현과 스키마를 분리하여 관리하므로 유연한 데이터 유효성 검사가 가능합니다.
