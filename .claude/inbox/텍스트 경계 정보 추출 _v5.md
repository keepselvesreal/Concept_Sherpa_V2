- 너는 정확한 텍스트 추출 스크립트 작성을 도와주어야 해
- 우선 리프 노드에 해당하는 부분을 정확히 파악해. 이때 맥락을 고려하여 페이지 상단에 나타나는 페이지 헤더와 실제 섹션 제목을 분명히 구분해야 해야만 해
- 그 후 리프 노드 텍스트 추출을 위한 시작, 종료 문자열을 10-15자 이내로 추가하여 7장의 리프 노드만 담긴 새로운 json 파일로 저장해줘
- 추출 패턴 정의
    - 각 리프 노드 텍스트 추출을 위한 시작 문자열과 종료 문자열을 정의해
    - 문자열 길이: 10-15자 이내로 제한
    - 고유성과 정확성을 보장할 수 있는 패턴 선택
- 검증
    - 제안한 패턴이 다른 부분과 중복되지 않는지 확인
    - 페이지 경계나 특수 문자로 인한 오추출 가능성 점검
