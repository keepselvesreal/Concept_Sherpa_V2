이번에 진행한 작업에 대한 기록을 프로젝트 루트의 records/오늘 날짜 폴더{yy-mm-dd}에 cm-report-{전체 작업 내용 압축적으로 표현하는 이름}.md 파일로 저장해줘. 불필요한 내용은 포함시키지 마. 오늘 날짜는 date 명령어로 확인.
위 보고서와 이번에 진행한 모든 작업 내용만 스테이징해줘. 
아래 형식에 맞춰 적절한 커밋 메시지를 '제안'해줘. 커밋 진행까지 하면은 안돼. 

## 커밋 메시지 형식
```
목표 달성 여부: {사용자 입력 내용에 적절한 이모지} | {작업종류 접두사}: {전체 작업 내용을 압축적으로 표현하는 이름}

- (달성하지 못한 목표가 있는 경우) 남은 문제: {자의적으로 판단하지 말고 사용자 입력 내용을 바탕으로 추측한 남은 문제}
- 이번에 진행한 작업에 대한 핵심 내용들만 책의 목차처럼 제시

커밋 시각 (KST): YYYY년 MM월 DD일 HH시 mm분(실제 date 명령어로 확인된 시간 사용)
```
## 접두사 예시 (작업 종류)
* `feat`: 기능 추가
* `fix`: 버그 수정
* `refactor`: 리팩토링
* `test`: 테스트 코드 추가/수정
* `docs`: 문서 작성/수정
* `chore`: 기타 작업
