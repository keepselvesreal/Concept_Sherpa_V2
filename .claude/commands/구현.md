# 목표 
- 이후 사용자가 제공할 안내 문서를 바탕으로 구현을 진행해줘
    - 입력, 생성 결과 또는 출력은 눈에 띄게 표시해줘
    - 오류 발생했던 부분은 주석으로 간단 메모와 함께 눈에 띄게 표시해줘
- 작업할 프로젝트의 로거를 활용해 구현 시 로그 파일을 작성하고, 문제 발생 시 이를 바탕으로 문제 해결해줘
- 한국어로 답변해줘
- 구현 진행 전에 진행할 구현에서 파레토 법칙의 20%에 해당하는 내용을 눈에 띄게 제시해줘
- 구현 작업을 진행하는 데 문제가 있는 부분, 헷갈리거나 확실히 이해되지 않는 부분이 있다면 반드시 알려줘
