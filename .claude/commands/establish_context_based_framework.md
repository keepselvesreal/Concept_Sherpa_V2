# 맥락 기반 작업 가이드

1. 사용자와 대화를 통해 다음 항목을 명확히 정의하고 최종 확인 받기(파일에 기록하고자 하는 내용을 제시한 후 맞는지 명시적으로 확인 받기)
- 수행할 작업 내용와 작업 이름
- 작업 목표와 기대 결과 
- 성공 기준

2. 작업 맥락을 기록할 파일 생성하고, 내용 기록하기
- @records/오늘 날짜 폴더{yy-mm-dd}(없으면 생성)에 {작업 이름}.md 생성
- 아래 항목과 해당 내용 기록
    - goal
    - Expected_outcomes 
    - success_criteria
    - context: {수행할 작업 관련 기록을 자세히 기록}
    - process_log:
        - {작업 수행 과정에서 문제 발생하여 사용자에게 현재 상황 보고 또는 질문 시 해당 문제를 기록} 다음 작업 수행 시마다 이전 작업 내용 기록되게. // 이건 그냥 내가 명시적으로 커스텀 명령어 사용해서 수행하는 게 나을 듯? 아니다. 근데 이러면 내가 깜빡할 수. 그리고 나름 기록 잘 하는 듯함 안 까먹고.

* 주의
- 기존에 작성된 내용은 절대 수정하지 않기. 수정 내용은 추가로 작성하고, 어떤 내용을 수정한 것인지 명시
- 작업 성공 여부는 사용자만 판단 가능
- 사용자가 수행하려는 작업이 바뀔 때마다 위 과정을 처음부터 반복하기
